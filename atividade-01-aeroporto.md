Atividade Prática 01 - Conceito de Dado e Informação

1. Levantamento dos dados

- Dados dos passageiros
- Dados das aeronaves
- Dados das passagens
- Dados dos funcionários
- Dados dos voos
- Dados das companhias aéreas
- Dados das bagagens

Dados dos passageiros: Nome, CPF, Idade, Número de telefone 

Dados das aeronaves: Tipo de aeronave, Horários previstos, Números de operações 

Dados das passagens: Horário do voo, Número do assento, Código de reserva, Nome do passageiro, Documento do passageiro 

Dados dos funcionários: Nome, CPF, Idade, Cargo, Salário, Número de telefone 

Dados dos voos: Número do voo, Horário de partida, Horário de chegada, Modelo da aeronave 

Dados das companhias aéreas: Voos programados, Despacho de bagagens, Taxa de atrasos, Taxa de cancelamento de voos

Dados das bagagens: Peso da mala, Nome do passageiro, Número único de rastreio

2. Informações que o sistema deverá fornecer

- Quantidade de passageiros em um determinado voo
- Voos atrasados
- Peso que está sendo transportado
- Quantidade de bagagens por voo
- Quantidade de voos de uma determinada companhia
- Voos cancelados
- Histórico de voos dos passageiros
- Quantidade de pilotos
- Histórico de voos dos pilotos
- Portão de embarque de cada voo
- Quantidade de voos por dia
- Quantidade de funcionários por voo
- Rastreio das bagagens
- Fluxo de passageiros
- Rotas mais comuns
- Horários de voos mais comuns
